\begin{abstract}
A language-specified target is often hidden from the camera while the object sits in a dexterous hand, so the robot has to look before it can present anything. We introduce REVEAL, an agentic framework in which the agent decides where to turn the object and for how long, reads the mark from whatever view it produces, and picks the orientation the hand should present. Underneath, a local policy built on an occlusion-robust pose estimator keeps the object tracked and held steady through the seconds each decision takes. Because every view is chosen rather than scheduled, the hand keeps finding the mark while it holds the object; giving the same agent repeated chances with the first frame instead of the current one recovers little of that gain. On six simulated objects REVEAL reaches \QOneOriginalSuccess\% mean success against \QOneOriginalBaseline\% for the strongest baseline, and on four physical objects it completes \HardwareAimiSuccess\% of trials against \HardwareFineTunedSuccess\%. What an agentic system contributes to a dexterous hand is therefore not a better goal but a better view.
\end{abstract}
