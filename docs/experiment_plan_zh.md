## 仍缺的正式数据

1. 其他四个物体。每物体3方法×40，匹配初始状态，分别报告对象结果及有效分母。约五物体是研究计划，不是接收保证。专属student需披露训练预算及资产接口，不能声称零样本迁移。
2. 同事负责的predictor改进。先比较独立姿态误差，再固定student、agent和控制器做各40次闭环。需要适配policy时另列一组。
3. 同事负责的真机。每条件40次、两session，独立姿态评分，同步视频和调用/动作日志。至少一个物体补关键等待控制对照，检验接触稳定收益能否转移。
4. 模型服务版本、完整去敏prompt/tool schema、匿名复现包及最终人工审稿。

若声称纯反馈机制收益，补等调用预算对照。若声称控制收益跨物体普遍成立，在第二个物体复验关键控制对照。它们是相应主张所需证据，不能用现有不同预算或单方块结果替代。

## 口径和复算

成功定义保持不变：停止时正确语义绑定且真实角度误差≤0.16 rad，停止决策使用预测姿态。服务异常和超过120秒调用按既定规则对称剔除，所有原始槽位保留。普通掉落、错误绑定、错误停止与时域耗尽仍是失败，不补采替换。

最新归档包是760次live语义记录和160次固定计划开发回放。视觉360次包含旧归档中的240次裸VLM记录，不能重复计数。主实验、等待、反馈、图像干预和开发回放不可合并出一个总成功率。
