\begin{abstract}
A visual agent can identify the object face requested by a user, but a dexterous hand must maintain contact while that decision is being computed. We study semantic in-hand reorientation with asynchronous visual reasoning and continuous physical execution. \method connects a visual agent to a pose-conditioned recurrent student through a common semantic goal representation. Lightweight local controllers adapt joint targets using measured state and public request history, supervised by a privileged teacher during training. On a marked cube with 40 matched trials per system, the full Astra system achieves 87.5\% autonomous semantic success, compared with 75.0\% for a bare fine-tuned VLM and 42.5\% for a bare rule VLM. A separate waiting ablation gives 62.5\% for continued execution and 85.0\% for learned slowing with joint correction. The Astra--fine-tuned difference and the three adjacent waiting contrasts remain statistically unresolved. With the same motor controllers, continued feedback raises completion from 6/39 with one initial plan to 33/39 with up to six calls. Under a controlled letter--color remapping, Astra retains 32/40 successes while the fine-tuned model falls from 30/40 to 16/40. \end{abstract}
