## Frozen conclusion

Under this cube protocol, later upper-level RGB evidence improves autonomous completion with live numeric feedback, history, lower perception and control retained. The paired difference is +57.5 percentage points, with 23 fresh-only and zero frozen-only successes. Exact paired p=2.384185791015625e-7, Holm p=4.76837158203125e-7 across the two predeclared primary comparisons. This is not an equal-realized-compute experiment or removal of all visual sensing.

Independent controller confirmation does not establish superiority over fixed slowing: 30/39 versus 31/39, six versus seven exclusive successes, Holm p=1. Learning has zero observed waiting drops and eight execution drops. Phase labels locate failures without identifying their cause. The waiting action changes later states even though execution weights are fixed.

## Archive contract

- summary.json, trials.json and evidence.json are byte-identical copies of the independent audit outputs. The latter preserves image and transport hashes and timing checks, without credentials or model private reasoning.
- completion_verification.json binds those files to the frozen release. statistics_audit.json records the separate SciPy recomputation.
- release_export.json contains only the public protocol subset and the complete source release hash. PROTOCOL.md records the two distinct cohorts and registered tests.
- Slot 187101004 encountered an HTTP 503 overload in the continue arm. It is retained, excluded symmetrically across the controller panel, and never replaced. Only unvisited slots were resumed. The image panel has no service exclusion.
- SHA256SUMS freezes every file in this directory except itself. The renderer verifies it before recomputing counts and paired tests from all raw trials.
- Keep this snapshot immutable. Future work belongs in a separate release and cohort. Do not pool this confirmation with historical development or waiting studies.

Reproduce tables with `python3 scripts/render_confirmation_image.py` from the paper root. Full logs and weights remain in the project experiment archive under `confirm_wait_image_20261102_v1`.
