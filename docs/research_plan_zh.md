# 研究计划与讨论稿

更新：2026-09-18。以下区分已确认方向、建议和待验证假设，不等同于已完成的方法。

## 已确认的研究问题

任务：根据语言找到手中物体的指定表面或标记，将其转到观察相机可清晰看到的位置，并稳定展示。目标可以在初始时被物体自身或手指遮挡。

RQ1：不使用人类任务操作示范，能否学会语言引导的目标搜索与稳定展示？

RQ2：交互学习能否改善有限示范覆盖不到的探索和恢复行为？

RQ1 不等于零外部数据：允许视觉语言编码器预训练，允许仿真奖励，但必须披露来源。RQ2 是待检验的问题，不能以“手内操作示范难采集”直接推出 RL 更优。难采集说明研究动机；受控实验才能说明性能、覆盖和成本差异。

## CVPR 叙事应该落在哪里

应将贡献落实为视觉信息与动作的闭环：看不到时怎样选择动作获取证据，已看过的信息怎样在遮挡后保留，以及怎样在接触稳定约束下展示目标。

只做“语言对应一个固定面编号，然后已有控制器转过去”，视觉问题太弱。只拼接语言、GRU 和 PPO，也不足以形成方法贡献。可以争取的三层证据是：任务定义能暴露已有方案的失败；机制相对强基线有稳定收益；收益来自声称的探索或恢复能力。

Agentic robotics 可以作为定位，但不能替代机制描述。论文中应具体描述观察、动作、证据更新、再决策和稳定保持。

## 方法候选：面向表面的证据记忆

直觉：同一个动作既改变接触状态，也改变哪些表面能够被可靠观察。策略需要区分“没看过”“看清过但不是目标”“目标曾经出现、现在被遮住”，而不是将所有不可见状态混在一起。

候选整体流程为：当前图像与语言编码 → 更新可见表面的证据 → 与本体感觉融合 → 同一个策略直接输出 21 维关节动作。这个流程符合统一策略的方向；是否使用独立识别头、停止头或预测头仍待讨论。

| 候选表示 | 潜在收益 | 必须解决的问题 |
|---|---|---|
| 普通 GRU / Transformer 历史 | 实现简单，作为强基线 | 未必显式区分区域覆盖和遮挡，不能预设它一定失败 |
| 物体坐标系中的表面槽位 | 区域对应和访问历史更明确 | 位姿与对应关系必须从允许的观测估计，不能偷用真值 |
| 学习的视觉证据 token | 少依赖几何先验 | 旋转后如何对应，如何校准“看清了”的置信度 |

先观察普通历史 PPO 在重复查看、错误排除目标、遮挡后回到目标方面是否存在系统性失败，再决定显式记忆是否值得做。不要先固定复杂结构，再寻找有利任务。

可证伪预期：在相同编码器、观测、奖励、PPO 预算和近似参数量下，候选机制减少无效重复查看，并在目标短暂遮挡后更快恢复展示，且不以明显更高掉落率换取。没有这些证据，就不应宣称记忆机制有效。

## 第一阶段：先完成最小可解释实验

| 阶段 | 工作 | 完成标准 |
|---|---|---|
| P0 任务校准 | 随机标记布局；目标可见性、投影面积、速度和 dwell；固定隐藏/可见初始状态集 | 正面但被手指挡住不能判成功；短暂露出后掉落不能判成功；不同语言在同一物体上要求不同目标 |
| P1 学会任务 | 扫描识别保持、普通视觉语言历史 PPO、候选方法 PPO | 相同任务与预算；分别报告搜索、展示和掉落；候选方法用消融解释差异 |
| P2 交互是否有用 | 一个认真实现的语言条件 DP；同架构 BC 与 BC→PPO；增加数据的 BC 控制 | 不同数据预算；共享扰动状态；记录数据生成及交互成本；至少 3 个训练种子 |
| P3 外部强方法 | VLM 闭环规划 + 共享控制器；UniDex checkpoint 适配 | 先核对输入、Revo3 动作接口、开源权重、适配算力，再决定实际纳入哪些 |

P0 和 P1 是当前优先级。P2 是研究问题的一部分，不能永远以“IL 很难”为由省略，但不需要同时移植大量 IL 模型。P3 的规模由初期结果和时间决定。

若扫描识别已接近性能上限，应首先检查任务是否过于简单，或报告其成本优势。只能基于真实需求增加歧义、遮挡和恢复条件，不能为了制造 baseline 失败任意加难。

## 数据设计与公平比较

先使用仿真生成示范，而不是等待人类遥操作系统。示范生成器也必须通过观测搜索目标；隐藏目标真值不能直接充当搜索答案。只收集“已知目标在哪里”的重定向轨迹，再要求 IL 完成探索，会形成不公平的数据缺口。

可提出若干示范规模，例如 100 / 500 / 2000 条完整轨迹；这些数字尚未冻结，应根据成功轨迹长度和预算调整。记录轨迹数、状态动作步数、任务覆盖、失败样本处理、生成器训练成本和筛选成本。

RQ2 主张的强度要区分：BC→PPO 比 BC 好，首先说明额外交互有帮助；只有加入同等采样预算下的 BC 数据扩充控制，才更有依据讨论强化学习目标本身的收益。DP 与 PPO 结构不同，单独比较不能隔离“学习范式”的因果作用。

扰动评估从共同状态出发，包括有限物体扰动、暂时遮挡、初始抓取变化和语言目标切换。先固定扰动幅度与恢复时限；训练中是否见过同类扰动也必须报告。

## 无实机的边界

没有实机并不自动排除 CVPR 投稿；最终按当年要求核对。对本方向而言，纯仿真更需要清晰的视觉问题、可信的闭环任务、跨布局与物体的泛化、强基线和可复现性。实机结果能显著加强应用价值，但没有实机时不能声称已证明部署可靠或 sim-to-real。

DexArt 是相关的仿真 benchmark 先例，不能用它保证当前任务的贡献足够。项目目标应先是站得住的研究证据，而不是先承诺某个会议录用。

## 下一轮优先讨论的三个决定

1. **标记与语言复杂度**：建议先做颜色 + 形状 + 简单图案的组合、随机换面；自然图案与文字后续扩展。单纯六个固定颜色只用于调试。
2. **传感器与输出**：建议先用已有固定 RGB-D 相机和统一 21 维动作；若定位为 RGB-only，应从主实验开始统一。RGB-D 还是 RGB 当前尚未确认。
3. **方法投入点**：建议先建立历史 PPO 的完整闭环，观察具体失败后决定表面记忆的形式。已有后果预测器暂不默认作为主方法。
