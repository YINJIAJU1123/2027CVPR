# Six-object semantic-mapping results

This folder contains the six-object Q1 mapping results reported in the paper, including per-object summaries and the accompanying audit records. Each object has an object-specific perception and motor-policy release; these are complete-system comparisons and do not measure zero-shot policy transfer. Raw trial details for the cube controller-confirmation and image-refresh studies are in the adjacent `../cube_confirmation_image_refresh_20261102/` directory, together with the protocol and statistical audit.
