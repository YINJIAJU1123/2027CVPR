\begin{abstract}
A visual agent can identify a requested object face, but a dexterous hand must maintain contact while the decision is computed. We study semantic in-hand reorientation with asynchronous reasoning and continuous execution. \method connects a visual agent to a pose-conditioned student through a common goal representation. Small local controllers adapt joint targets from measured state and request history, using privileged teacher supervision during training. On a marked cube, the full Astra system completes 35/40 trials, compared with 30/40 for a bare fine-tuned VLM and 17/40 for a bare rule VLM. Independent confirmation gives 30/39 for learned waiting control and 31/39 for fixed slowing, leaving its advantage unresolved. Continued feedback raises completion from 6/39 for one initial plan to 33/39 with up to six calls. A separate image intervention with the same call cap gives 32/40 with current images versus 9/40 with repeated initial images. In a separate dice layout study, Astra completes 28/40 identity trials and 26/40 after visual-layout rotation. Fine-tuning falls from 23/40 to 0/40 and rules from 13/40 to 1/40. These system-level results support continued visual feedback while exposing contact-control limits. \TODO{Add further objects and hardware results.}
\end{abstract}
