# 任务合同与 baseline 矩阵

状态：建议协议，尚未冻结。更新：2026-09-18。

## 语义 baseline 不等于必须使用大型 VLA

主对比应获得同一条语言指令和相同可部署观测。它可以用小型图文编码器 + GRU + PPO，也可以用语言识别模块 + 扫描控制器。VLA 广义上是视觉、语言到动作的映射；预训练通用 VLA 则额外引入大规模预训练与跨任务先验，两者不能混为一谈。

| 方法 | 语义入口 | 动作与记忆 | 训练/数据 | 回答的问题 | 优先级 |
|---|---|---|---|---|---|
| 扫描 + 识别 + 保持 | 与指令匹配的可见目标识别 | 固定扫描规则 + 共享低层目标控制器 | 控制器训练成本单列 | 简单探索是否足够？ | P1 |
| 历史策略 + PPO | 同一图文编码器与指令 | GRU/Transformer，直接 21 维动作 | 同奖励、同交互预算 | 普通统一策略能做到什么？ | P1 |
| 候选证据策略 + PPO | 同上 | 候选证据记忆，直接动作 | 同上；额外标签或奖励单独消融 | 证据机制是否超过一般历史？ | P1 |
| 语言条件 Diffusion Policy | 加入同一语言特征 | 动作块，匹配可用历史 | 相同仿真示范，数据规模曲线 | 纯固定数据学习的能力和覆盖？ | P2 |
| 同架构 BC / BC→PPO | 同一编码器与指令 | 同一策略家族和初始权重 | 固定数据；随后等预算交互 | 交互带来的变化是什么？ | P2 |
| VLM 闭环规划 + RL 控制器 | VLM 接收语言与图像历史 | 更新连续目标；共享低层执行 | 控制器、API 调用、延迟均记账 | 分层系统是否已足够？ | P3 |
| UniDex 适配与微调 | 公开预训练模型的语言接口 | 适配点云/本体/动作接口 | 外部预训练和任务微调分开报告 | 通用 dexterous VLA 的迁移能力？ | P3 |

DP 必须标记为语言条件适配版本。扫描和 VLM 尽量共享同一个低层控制器及目标接口；直接动作 PPO 不强行改为分层结构，这一差异是系统比较的一部分。UniDex 若使用不同模态或预训练数据，单列条件，不能称为严格等信息机制对照。

无语言、打乱语言、目标编号真值、识别真值和位姿真值分别是消融或 oracle 诊断，不替代主语义 baseline。Privileged oracle 不能与部署策略混在同一不加说明的排行榜中。

## Actor 可用信息

- 同一固定相机，RGB 或 RGB-D 待确认；同一分辨率、时延与视角。
- 本体感觉、上一动作、指令及允许的历史。
- 相同 21 维动作语义、关节限位、动作频率与滤波。

不可输入隐藏目标面编号、真值物体位姿、背面纹理表或完整真值语义分割。奖励、critic 和评价可使用仿真真值，但不能通过 observation、debug marker、reset 参数或 reward history 泄露给 actor。布局不能由可见物体 ID 唯一反推。

## 成功必须同时满足什么

设目标区域为语言所指的唯一标记。每个控制步检查：目标的可见比例达标；投影像素面积足够；朝向相机的角度在可读范围内；物体线速度和角速度低于阈值。最终连续保持一个 dwell 窗口，且整段 episode 未掉落，才记作 terminal success。

可见比例用相同姿态下目标区域的无遮挡投影为参考，结合深度/实例遮挡检查；背面或接近零投影不能因为比值高被误判。人工审核一小组渲染样例，确认度量与可读展示一致。

建议先校准 1 秒 dwell；原工程的 0.5 秒和 0.16 rad 不是自动继承的新任务阈值。最终 `v_min`、`A_min`、朝向阈值、速度阈值、horizon 和扰动时限在比较前冻结，按物理时间报告。实验结果不可反过来决定对某方法有利的阈值。

相同表面可以有多个合法姿态；除非语言要求“正立读字”，不要把固定 yaw 当作成功必要条件。

## 指标与切分

| 指标 | 用途与注意事项 |
|---|---|
| Terminal stable presentation | 主指标；最终 dwell 满足展示与稳定，且无掉落 |
| First clear exposure | 搜索效率；几何曝光不等于内部识别正确 |
| First complete display dwell | 包含搜索和稳定；同时报告失败/超时，不能只对成功 episode 平均 |
| Ever dwell vs terminal dwell | 揭示“曾经成功但后来失去目标” |
| Drop / wrong-target declaration | 区分控制失败与语义错误；后者仅适用于带声明输出的系统 |
| Recovery success and time | 从共享扰动状态出发，在同一时限内重新稳定展示 |
| Revisit / inspected-region coverage | 检验探索机制；定义需以观测证据而非任意动作步数为基础 |

切分至少包括随机布局、未见属性组合和未见物体实例；未见几何可后续增加。训练/验证/测试按物体与布局配置划分，禁止相邻帧随机划分造成泄漏。先报告隐藏目标与初始可见目标两个子集。

每个主学习方法建议至少 3 个独立训练种子，同一组配对评估 episode。报告各训练种子的均值、离散程度，以及以训练种子为独立单位的区间或层次 bootstrap。不要将一个 checkpoint 的数百条 episode 当成数百次独立训练。

## 预算与 IL 数据覆盖

主表同时记录：人类任务示范数、仿真示范轨迹数/步数、预训练来源、在线交互步数、教师或低层控制器训练步数、GPU 小时、推理延迟和 VLM 调用数。

有限示范不应刻意缺失全部搜索行为。使用可观测的扫描识别系统等生成完整轨迹；如果还测试只含重定向的窄覆盖集，明确作为覆盖消融。成功轨迹过滤、失败轨迹丢弃和特权教师应透明记录。

主要受控比较：相同 BC 初始化的 BC-only 与 BC→PPO，再加入匹配采样预算的数据扩充 BC。若仅有 BC→PPO 对比 BC，结论限于额外互动有帮助；不能单独归因于 RL 算法优于 IL。
