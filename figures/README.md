# AIMI paper figures

The active main and supplement use the six vector crops `imported/aimi_*.pdf`, exported from `AIMI_paper_figures.pptx`. The existing slide geometry, gradients, fonts and embedded simulation images are preserved. The teaser is a staged simulation illustration. Empty physical-hand slots are retained for author-supplied evidence.

Regenerate with `python3 scripts/export_aimi_figures.py` (LibreOffice and PyMuPDF), or pass `--from-pdf path/to/AIMI_paper_figures.pdf`. Normal LaTeX compilation uses the checked-in vector PDFs directly.

`method.pdf` is a supplementary deployment schematic, not a measured trajectory. `feedback_example.pdf` contains unchanged model-input frames and recorded public decisions from the Q3(a) cohort, whose feedback arm reuses the initial Q2 seed 187102. Historical trial filenames in the source archive are preserved; they do not identify additional Q2 seeds.

`controller_outcomes.pdf` is the current Q2 result figure, generated from the three-seed aggregate by `scripts/render_result_presentation.py`. The four rows each contain 120 trials; the combined study has 480 outcomes. `language_objects.png` is generated from the existing numeric LaTeX table; its source/image hashes are checked during builds.

Other legacy figures and the earlier source deck are retained locally for provenance. In particular, `waiting_feedback.pdf` and `cube_results.pdf` are historical figures, not the current three-seed Q2 evaluation. They are not included in the active paper.

## 2026-11-08 result charts

`q1_task_success.pdf` replaces the main six-object mapping table; the table remains in the supplement. `hardware_task_success.pdf` shows the four physical objects with 20 trials per bar. Both charts are generated by `scripts/render_task_success.py`, using grey/orange/blue for Rule/Fine-tuned/AIMI. Numerical inputs, sums and source hashes are saved in `task_success_values.json`. PDF, SVG and PNG exports are provided.

The vector real-case export now labels its four photo slots Cube, Die, Ball and Duck. The editable AIMI PPT and its vector exports both label the four slots Cube, Die, Ball and Duck. The export script retains a compatibility relabel step for older PDF exports. Layouts, gradients, fonts and embedded images are preserved.
