\begin{abstract}
Language-guided in-hand manipulation requires a robot to uncover a requested object face while maintaining contact. This couples visual information gathering with motor control, yet high-level visual reasoning introduces delays during which the hand must continue acting. We present REVEAL, an asynchronous framework for online visual search and semantic target presentation. The agent uses updated images to inspect the object and bind the requested target to a shared goal bank, which interfaces with a history-conditioned motor policy. Teacher-supervised local controllers adapt joint commands during pending requests and subsequent execution. Simulation evaluations cover six object-specific systems, with additional English/Chinese instruction tests on three objects. Under changed semantic mappings, REVEAL achieves an object-averaged success rate of \QOneChangedSuccess\%, exceeding the strongest evaluated baseline by \QOneChangedGain{} percentage points.
\end{abstract}
