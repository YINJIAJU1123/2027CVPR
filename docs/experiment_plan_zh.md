# 论文实验计划与当前缺口

更新：2026-10-30。论文结构维持四部分：五物体主比较、方块机制消融、predictor改进、真机。结构完整不等于证据完整。未完成结果保留TODO，不填写假数据。

## 统一报告口径

主成功率为成功数除以服务有效试验数。方法对比取同一批初始状态，并对称排除任一方法的预注册服务异常。普通掉落、错误绑定、错误停止和超出任务时域仍计为失败。原始记录和服务可用性另报，不补采替换失败或被排除槽位。每条件计划40个原始槽位，因此有效分母可能小于40。物理成功定义、停止规则和权重继续冻结。

## 模块结论与研究重点

完整控制相对固定减速的有效成功率增加18.9个百分点，总掉落16降到10，但配对p=0.210。完整相对仅执行恢复只净增一次成功（8胜7负，p=1.0），执行阶段掉落4升到9。等待和执行的协调仍是需要解决的技术问题。不能宣称两个模块都已证明必要或有稳定协同收益。

最新有效失败集中在初次等待、无绑定观察和正确目标下发后的短时间内。下一版可以在独立开发集训练稳定观察和状态相关的接管策略，把最终完成率与掉落风险共同纳入目标。不能针对当前正式评测失败反复选择checkpoint，再把同一评测当作未见测试。

显式actor目标路径没有得到当前配对诊断支持。student在两种条件下都收到正确目标，动作变化不能独立证明actor使用目标的价值。必须完成正确/无显式/打乱三组，或按证据缩小论文贡献主张。

## 五物体主比较

完整计划为5×3×40=600个原始槽位，按同一协议、每物体分别报告有效成功率、分阶段失败和服务异常。不要用五个贴图变体替代几何、惯量、接触和语义可见性差异。五物体不是会议接收门槛。

允许每物体使用专属student，但必须说明训练数据、预算、标定、物体尺度、动作约定、goal bank和checkpoint。不能称为零样本跨物体迁移。若换底层或控制器，发布新版本并复验方块，不能混用不同版本的行。

方块做完整消融是合理的。若论文主张学习控制普遍适用，建议在第二个物体复验最关键的完整/基线对照，不必复制全部矩阵。

## Predictor数据交接

同事需要提供：原始与改进predictor版本、独立参考姿态来源、训练测试划分、物体与相机标定、平移/旋转误差及尾部误差。先在固定student、agent和控制器下做各40次闭环比较。若还需适配policy，作为第二阶段另报。

现有CNN-feedback DAgger训练的是student，没有更新CNN，不能用于声称pose estimator贡献。当前也没有公平真机证据支持“我们的predictor优于ViserDex真机版本”这一结论。

## 真机数据交接

论文目前只有方案，没有可验收的真机成功率。同事需交付：

1. 手、相机、物体尺寸质量、控制频率、标定和物体模型对应关系。
2. 同物体下完整方法、裸微调VLM、裸规则VLM各40个预定试验，分两次session各20次，方法顺序交错。
3. 独立于部署predictor的目标面/姿态判定。共享停止规则，记录重置误差和匹配容差。
4. 包含成功和失败的连续视频，以及同步的请求、返回、关节命令、掉落和停止时间戳。
5. 服务错误和长延迟单独记录，按相同预注册排除规则处理。

若要声称“学习等待/恢复在真实接触中有效”，主方法真机视频还不够。至少在一个真机物体上补完整方法与固定减速/无恢复的关键对照，并报告等待与执行阶段掉落。这属于Q4中的机制验证，不必新开大实验章节。

## 其余论文准备

- 继续保留共享控制的VLM辅助对照，完整系统比较不能等同于上层模型能力比较。
- F实验同时报告实际调用数、延迟、完成时间。一次调用和六次预算的对比不能单独归因于新视觉信息。
- 新版本冻结前明确核心learning贡献，避免把每一个软件模块都列为已证明有效的贡献。
- 主文页数、图示、复现说明、匿名包和引用需要最终人工审核。
- 确认相关工作和新颖性时必须重新检索，当前不作“首个”或保证接收的结论。
- 目前不需要额外扩展光照/背景泛化，优先把原场景中的机制和多物体结果补齐。

## 建议收尾顺序

先跑完独立复验、G和F以及Astra视觉干预，形成完整且诚实的机制结论。同时接收物体和predictor材料，让真机同事按上述口径采集。根据证据决定哪些模块保留为核心贡献，再统一版本、完善主图、压缩正文并核对匿名提交包。
