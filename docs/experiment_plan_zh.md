# 论文实验计划与当前缺口

更新时间：2026-10-29。所有 TODO 都是未完成实验，不是零分，也没有模拟出来的成功率。

## 论文主问题

视觉语义 agent 发起推理时，灵巧手仍处在持续接触动力学中。我们学习本地控制，利用当前感知、有效目标和请求历史决定怎样等待、怎样执行。最终要证明这些学习到的行为提升自主语义完成率。

“用了 Astra”“第一次语言手内旋转”“首次处理等待延迟”都不能独立充当新颖性。VERA 已有语言控制的手内旋转，ARLI、A2C2、RTC、DEFLECT、LiMA 都需要认真讨论。

## 最优先的三项机制证据

1. **语义有没有真的用到视觉**：原场景内更换字母与颜色的绑定、遮挡文字/打乱图像，并有 text-only 对照。当前固定布局可以被记住。无需先做大范围光照泛化。
2. **本地控制有没有真的用到目标**：等参数量、等数据量的无目标 actor，加上同一状态不同目标、打乱目标的干预。比较动作方向、掉落和最终成功，而不只比较 latent 距离。
3. **agent 的反馈有没有价值**：同一 Astra 和同一控制器，一次调用、去除历史/验证、完整闭环。匹配调用上限，报告真实调用数和时间。需要分开真实在线模型实验和固定公开计划回放。

## 公平性与统计

主比较按用户约定，VLM 微调/规则均不加载等待与执行 actor。已有 VLM+相同 actor 的辅助结果必须保留：微调 VLM 30/40，规则 VLM 16/40。不能只看有利的主表就断言 Astra 天生更强。

主表统一 eligible 集合上 Astra 29/39、微调 26/39、规则 13/39。Astra 对微调的精确配对 McNemar p=0.607，现阶段不能宣称显著更好。40 次是每个条件的一批，不是保证能检出小差距的样本量。若需要复验，用新的 40 次批次，不重复调参使用已有正式种子。

每个物体单独统计，完整后再做物体宏平均和配对分析。不同物体使用各自 student 必须披露，不叫 zero-shot。多物体新增 4×3×40=480 次主比较。模块机制优先做有诊断价值的子集，无需机械地对所有物体做所有消融。

## 新 student 为什么训练

把同事的 pose-goal student 迁移成 latent student 后，观察到 reach 从 39/40 到 35/40。现在做两个等预算追加 DAgger 分支：模拟 pose 噪声与真实冻结 CNN 输出。每路 400 更新、288,000 新 transitions，CNN 和 teacher 不训练。目的是区分“多训练一些”的收益与“训练感知分布匹配部署”的收益。

四组新的开发诊断现已完成：原 student 39/40，冻结 latent 38/40，额外模拟噪声训练 39/40，实际 CNN 训练 40/40。掉落分别为 1、2、1、0。160 次物理日志全部有效，40 个初始状态逐一匹配。CNN 候选通过开发准入，但对冻结 latent 的精确配对 p=0.5，对等预算模拟训练 p=1.0，尚不能证明稳定收益。未自动部署。还要重新采集/拟合与新 student 相容的控制器，再发布新的语义评测版本。Cube-v1 已冻结，不覆盖。

## 五个物体够不够

没有“达到五个就能中 CVPR”的数量门槛。更关键的是几何/接触差异、语义歧义、主方法稳定优势、机制消融，以及真实系统证据。建议至少覆盖不同长宽比、非立方几何、不同惯量/接触面，不只换贴图。

## 建议执行顺序

1. 新 student 对照已完成，先验证 CNN 候选与控制器的兼容性，确定是否发布 cube-v2。
2. 锁定一个版本，先补语义与闭环机制实验，确保学习贡献成立。
3. 收第二物体 checkpoint 与完整资产，验证单物体接口迁移后再扩至约五物体。
4. 同事交 predictor 改进时先固定 policy 做对照。
5. 仿真方法冻结后同步真机，最后统一写主表与失败分析。
