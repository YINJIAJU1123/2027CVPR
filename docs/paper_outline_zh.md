# 论文结构与证据映射

当前是可编译研究骨架，不为凑页数扩写结论。以下是成熟稿的暂定篇幅分配，最终页数以 CVPR 2027 正式要求为准。

| 部分 | 目标英文词数 | 核心问题 | 所需证据 / 来源 |
|---|---|---|---|
| Abstract | 150–200 | 任务、关键困难、机制、定量结论是什么？ | 当前只有问题与计划；实验完成后加入真实结论 |
| Introduction | 550–650 | 为什么“找到并展示”超出已知目标重定向？ | 真实失败序列；ViserDex / UniDex 背景 |
| Related Work | 350–450 | 和视觉手内操作、VLA、active perception 的差别？ | 已核对 5 篇入口，继续覆盖近期相关工作 |
| Task | 450–550 | 怎样防止固定面编号捷径，怎样定义成功？ | 任务生成、指标校准、split 与信息合同 |
| Method | 800–1000 | 证据如何更新、影响动作、通过何种损失学习？ | 最终实现、训练协议与机制图；现在仍是候选 |
| Experiments | 1100–1400 | 是否能学、为什么有效、交互改善在哪里？ | P1/P2 主表、多训练种子、机制消融、恢复轨迹 |
| Limitations / Conclusion | 150–250 | 结论覆盖到哪里，哪些条件未验证？ | 仿真/实机边界、预训练数据与失败模式 |

正文暂按约 3400–4300 词规划，图表会影响实际版面。参考文献另列。

叙事顺序：具体任务困境 → 相邻工作已有能力 → 尚未解决的可检验问题 → 不泄漏答案的任务定义 → 候选机制 → 支持或否定机制的实验。不要先把 contribution 写死，再选有利数据。
